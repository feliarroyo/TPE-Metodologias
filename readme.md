# Guía del proyecto

## Branches
Cada vez que una entrega fue realizada, se guardó una copia como branch para tener constancia de la evolución del proyecto.

## Increment
Contiene los diagramas adicionales pedidos en las entregas (diagramas de secuencia/deployment).

## RefinedUserStories
Contiene la stories refinadas pedidas para cada entrega, escritas en forma de Markdown.

## Retrospectives
Minutas acerca de las reuniones realizadas, escritas en forma de Markdown.

## ScrumBoardSnapshots
Contiene capturas del avance de los Scrum Boards de cada entrega en el transcurso del tiempo.

## UseCaseSpecification
Carpeta que contiene las especificaciones de caso de uso del ciudadano en Markdown, así como un gráfico en forma de imagen

## UserStories
Carpeta que contiene las user stories y épicas elaboradas para la situación planteada, antes de ser refinadas.
También contiene:
- UserStoriesBacklog.xlsx: Planilla de Excel con la lista de user stories.


## CriterioDone.md
Redacción del criterio de Done en formato Markdown.

## DiagramaDeClases.jpg
Imagen del diagrama de clases de alto nivel, realizada en Drawio.

## UserStoryMap.pdf
PDF del user story mapping, realizado en Miro.

## Vision.md
Redacción del documento de visión en formato Markdown.
