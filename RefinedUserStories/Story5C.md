# User Story: Como ciudadano quiero que me envíen los datos del generador de la oferta si mi postulación fue aceptada para coordinar el viaje.

## Criterios de aceptación 
- Se debe contar con los datos del generador de la oferta.
- Si la postulación fue aceptada el ciudadano debe poder solicitar dichos datos.
- Se deben brindar todos los datos.
