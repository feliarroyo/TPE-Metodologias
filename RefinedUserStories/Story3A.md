# User Story: Como ciudadano quiero contar con una sección en la página de envío de solicitudes de recolección para que retiren mis elementos reciclables.

## Criterios de aceptación
- Se debe permitir contar con una sección de envío de solicitudes.
- Se deben ingresar los datos correspondientes para poder retirar los materiales reciclables.
- La solicitud debe ser enviada correctamente.
