# User Story: Como ciudadano quiero poder registrarme para que retiren los elementos.

## Criterios de aceptación
- Se debe permitir registrar un ciudadano.
- Se debe ingresar nombre, apellido, dirección y teléfono, franja horaria de preferencia dentro del rango ya establecido, y categoría a la cual pertenece  los materiales a retirar.
- Se debe poder ingresar una foto de los materiales.
- Confirmar registración.
