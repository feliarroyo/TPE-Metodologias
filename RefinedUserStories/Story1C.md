# User Story: Como ciudadano quiero que mi publicación de oferta sea posteada automáticamente en función a la información brindada para facilitar el proceso.

## Criterios de aceptación
- Se debe ingresar los datos necesarios de la oferta: nombre, teléfono, email, dirección, espacio disponible y un espacio de texto libre para cualquier detalle adicional.
- Para facilitarle el proceso al usuario, debe publicarse automáticamente dicha oferta con los siguientes datos: zona geográfica (calculada a partir de la dirección), espacio disponible y el texto libre.
