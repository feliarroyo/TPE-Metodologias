# User Story: Como ciudadano quiero tener una sección en la página que detalle la forma en la que se reciben los materiales aceptados para entregarlos de manera acorde.

## Criterios de aceptación 
- El ciudadano debe tener acceso a la sección de información de recepción de materiales.
- La sección debe describir con mucho detalle la manera en que deben ser entregados cada uno de los materiales aceptados.
