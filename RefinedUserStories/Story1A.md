# User Story: Como ciudadano quiero contar con una sección de cartelera en la página para publicar mis ofertas.

## Criterios de aceptación
- Debe permitir seleccionar la sección de la página para publicar ofertas.
- Debe pedir los datos del ciudadano ofertante.
- Se debe poder ingresar zona geográfica, descripción, y un contacto.
- La oferta debe ser agregada a la página.
