# User Story: Como ciudadano quiero contar con una sección de cartelera en la página para publicar mis ofertas.

## Criterios de aceptación
- El ciudadano debe tener acceso a la sección de la página para publicar ofertas.
- Se debe pedir los datos del ciudadano ofertante: nombre, teléfono, email, dirección, espacio disponible y un espacio de texto libre.
- Cada posteo debe mostrar zona geográfica, espacio disponible y el texto libre.
- Se debe poder agregar ofertas a la sección.
