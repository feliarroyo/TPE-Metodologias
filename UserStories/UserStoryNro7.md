# User Story N°7: Como secretaria quiero dar de alta empleados para mantener al día la base de datos respecto a nuevas incorporaciones.

## La secretaria quiere poder mantener su lista de empleados siempre al dia, para cumplir con sus deberes, por la cual debe poder dar de alta empleados en la base de datos.

### Criterios de aceptación

- Solicitar datos para dar de alta. Incluye datos personales (nombre, apellido, DNI, dirección, fecha de nacimiento), así como también el vehículo que utiliza.
- Debe obtener una cuenta al finalizar el proceso.
- Debe estar disponible solo a personas con permisos especiales.

### Tareas para su realización

1. Pedir datos.
2. Registrar datos y administrar la creación de su cuenta en el sistema.
