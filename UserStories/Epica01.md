# Epica N°1: Como ciudadano quiero reciclar materiales descartables, para deshacerme de lo que no me sirva y ayudar a cuidar el medio ambiente.

## Descripción

El ciudadano tiene la intención de reciclar elementos de su hogar. Por lo tanto, se informa acerca de la cooperativa y los elementos reciclables que aceptan; se registra en el sistema de su página web; y envía una solicitud de recolección para que los cartoneros pasen a buscar los materiales.

### User Stories que la componen:

- User Story 1: Como ciudadano quiero poder registrarme para que retiren los elementos reciclables.
- User Story 3: Como ciudadano quiero enviar una solicitud de recolección para que los cartoneros puedan venir a buscar mis elementos reciclables.
- User Story 4: Como ciudadano quiero ver los materiales aceptados por el centro de acopio para saber como puedo aportar.
