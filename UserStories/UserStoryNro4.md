# User Story N°4: Como ciudadano quiero ver los materiales aceptados por el centro de acopio para saber como puedo aportar.

## El ciudadano quiere estar al tanto de que elementos reciclan en el centro de acopio para poder llevar o aportar con dichos elementos reciclables.

### Criterios de aceptación

- Debe poder mostrarse una cantidad considerable de materiales, de manera tal que no sea una limitación.
- Debe ser flexible en la información que cuenta, opcionalmente con fotos.
- Debe poder modificarla un usuario con permisos especiales (como la secretaria), para adaptarse a la situación.

### Tareas para su realización

1. Verificar que el usuario tenga permisos.
2. Ingresar materiales / modificaciones a materiales.
3. Incorporar al catálogo.
