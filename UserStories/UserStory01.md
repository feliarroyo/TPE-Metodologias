# User Story N°1: Como ciudadano quiero poder registrarme para que retiren los elementos reciclables.

## Descripción

Un ciudadano quiere registrarse en el sistema para así consolidar con la cooperativa y aportar a su causa mediante el retiro de sus elementos reciclables.

### Criterios de aceptación
- Debe pedir datos personales.
- Debe permitir el ingreso opcional de una foto o un horario de retiro preferido.
- Debe verificar que los datos ingresados sean verídicos.


### Tareas para su realización

1. Pedir datos.
1. Verificar datos.
