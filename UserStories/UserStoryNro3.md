# User Story N3: Como ciudadano quiero enviar una solicitud de recolección para que los cartoneros puedan venir a buscar mis elementos reciclables.

## El ciudadano quiere poder dar aviso a los cartoneros para que retiren lo que reciclo.

### Criterios de aceptación

- Debe incluir un horario de retiro preferido entre los ofrecidos, y el volumen de los elementos a retirar.
- Se deben denegar las solicitudes a una distancia mayor a 6 km del centro de acopio.
- Se debe avisar por mail si se rechaza la solicitud al ciudadano que hizo el pedido correspondiente.


### Tareas para su realización

1. Procesar las solicitudes.
2. Da una respuesta por correo.
