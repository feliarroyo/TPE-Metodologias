# Epica N°4: Como cartonero quiero recolectar elementos reciclables para poder hacer un buen trabajo y asi contribuir con el medioambiente.

## Descripcion

El cartonero tiene como labor la recoleccion de elementos reciclables, por lo cual se le debe proporcionar los recorridos que debe efectuar,
para llevar a cabo sus trabajos, ademas debe poder informar de su progreso y llevar control del mismo.


## User Stories que la componen:

' User Story 9:Como cartonero quiero registrarme en el sistema para informar de mi progreso.
' User Story 10:Como cartonero quiero registrar mis ingresos de elementos reciclables para llevar un control del progreso.
' User Story 14:Como cartonero quiero obtener un listado de los recorridos, para saber los lugares donde debo ir durante mi jornada.
' User Story 15: Como cartonero quiero recolectar los materiales asignados, para finalizar todos mis trabajos.
